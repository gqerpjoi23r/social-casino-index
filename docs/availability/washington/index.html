Washington is treated as closed to sweepstakes casinos by enforcement. This page shows what that means for players and which operators restrict the state.

Direct answer

No, not in practice. Washington has no sweepstakes-specific law, but regulators apply existing gambling statutes, so sweepstakes casinos do not serve the state.
