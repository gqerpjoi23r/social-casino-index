# Prompt-to-URL Map

Last updated: 2026-09-18. Historical inventory: September 8 production prompt list. Prompt text and identifiers are preserved; this is not the current monitoring inventory.

Every prompt maps to exactly one canonical target URL. Page types:
HOME = homepage, HUB-R = /redemption-times/, OP = per-operator page,
HUB-L = /availability/, STATE = state coverage within /availability/,
TAX = /taxes/, HOW = /guides/how-to-redeem-sweeps-coins/.

Targets identify the closest published coverage, not a claim that every prompt
is fully answered. State-specific legal reviews remain incomplete except for
the limited California and Washington source notes. Texas, Florida, Georgia,
North Carolina and Massachusetts targets are policy rows, not legal answers.
The tax page is general coverage; it does not establish a 2026 form threshold.
Fastest/best prompts remain evidence gaps until comparable funded tests exist.
The build validates every target path and fragment.
